How Privio redacts

Last updated: 2026-10-XX
Applies to: PDF Privio 1.1.4 (build 70) on iOS and Android
Contact: mustafasalimerek@gmail.com

In short

  • Privio finds your search terms in the PDF’s text layer, renders every page to an image, burns black boxes into the pixels over the matched words, and builds a new PDF from those images. Nothing from the original file’s structure is copied into the new one.
  • It can only redact what it finds. Text inside images is not searched, and in this version a term split across two lines is not found. The known limitations are listed below.
  • Check every redacted file before you share it: how to check.
  • Privio’s redaction has not been audited or certified by an independent third party. This note describes the method as implemented in the app’s source code; it is not a test report.

1. The method, step by step

  1. Search terms. You enter one or more terms. Matching ignores upper and lower case unless you turn on case-sensitive matching.
  2. Finding matches. Privio reads the PDF’s text layer page by page and line by line, and looks for each term inside each line of text. For every match it takes the bounding boxes of the words the match touches, as reported by the text layer, and pads them slightly (1 point above, 2 points below). If the word boxes cannot be determined, the whole line is covered instead.
  3. No match, no change. If no term matches, Privio tells you so and produces no new file; your document is unchanged.
  4. Rendering every page. Every page — not only the pages with matches — is rendered to a JPEG image about 2,000 pixels on its long edge (roughly 180 dpi for a US Letter page; JPEG quality 88), using the platform’s PDF renderer (Apple PDFKit on iOS, Android PdfRenderer on Android).
  5. Burning. On pages with matches, Privio paints solid black rectangles into the image pixels over the matched word boxes and re-encodes the image.
  6. Rebuilding. Privio builds a brand-new PDF from the page images. The original file’s text layer, fonts, metadata, attachments, form fields, links, bookmarks and earlier revisions are not copied into it.
  7. OCR-back (“Keep non-redacted text searchable”, on by default). Privio runs on-device text recognition — Apple Vision on iOS, Google ML Kit on Android — on each redacted page image and adds the recognised text as an invisible text layer over the image, so the remaining text can be searched and copied. The recognizer only sees the burned images, so the black boxes contribute no text. With OCR-back off, the new PDF contains page images only, at the original page sizes, and has no text layer at all.

Everything above runs on your device; no page image or text is uploaded. (On Android, ML Kit sends Google its own diagnostic metadata, described in the privacy policy.) The free version and Pro run the same pipeline — Pro is needed only to save, share or export the result. The page images are written to the app’s private temporary folder during the run and deleted when it ends, whether it finishes, fails or is cancelled; if the app crashes or is force-quit mid-run, they stay there until the operating system clears the folder. The on-device audit log records the number of search terms, matches and affected pages — never the terms themselves.

2. Known limitations in 1.1.4

  • Only the text layer is searched. Text that is part of an image — a scanned page, a photo, a signature or a chart — is not found. Run a scanned PDF through the OCR PDF tool first; matches then depend on how accurately the OCR read the page.
  • A term must sit on one line, spaced as you typed it. A term broken across two lines (including a hyphenated line break), or with different spacing in the text layer, is not found. Planned for 1.1.5
  • No warning for unreadable pages. If a page has no text layer, or its text cannot be extracted, Privio treats it as a page without matches and does not tell you. Planned for 1.1.5
  • Matching is literal. The term must match the characters stored in the text layer. Ligatures (for example “ﬁ”), special hyphens or other character variants in the PDF can prevent a match.
  • Whole words are covered. A match inside a longer word blacks out the whole word: searching for “Ann” also covers “Annual” and “Planning”.
  • Boxes follow the text layer’s positions. If a PDF’s text layer does not line up exactly with the visible letters — this happens in some files — a box can miss part of a word.
  • Annotations and form fields. Text in comments, text boxes, stamps and form fields is not part of the page’s text layer and may not be searched. If such text is visible on the rendered page, it can appear in the output without a black box.
  • A page that cannot be rendered is left out. If the platform renderer fails to draw a page, that page is missing from the output. Compare the page counts.
  • Page size with OCR-back. With OCR-back on, each page’s size in the new PDF equals the image’s pixel size (one pixel per point), so a US Letter page becomes about 21.5 × 27.8 inches. Viewers scale it to fit, but printing at actual size, or an e-filing system that checks page size, may not accept it. With OCR-back off, the original page sizes are kept.
  • OCR-back languages. Text recognition for OCR-back is set up for English and Turkish; text in other languages may be recognised less accurately. This affects only searching the output, not what was redacted.
  • The output is an image-based PDF. It is usually larger than the original, its text is selectable only through the OCR-back layer (which can contain recognition errors), and form fields, links and bookmarks no longer work.

3. How to check a redacted file

  1. Compare page counts between the original and the redacted file.
  2. Search the exported file for every term, including variants: different case, spacing, line breaks, abbreviations and possessives. Keep OCR-back on for this, or run the exported file through OCR first — with OCR-back off the file has no text, so a search finds nothing either way.
  3. Look at every page at a zoom where you can read the text. Check that each box covers the whole term, and look for anything a search cannot see: images, stamps, handwriting, headers and footers, comments and form fields.
  4. Open the file in a second viewer (for example Adobe Acrobat or Apple Preview) and try to select and copy text around a box.
  5. For important productions, treat Privio’s redaction as one step and follow your own quality-control process.

4. Planned for 1.1.5

These changes are planned for the next update. Until it is released, the limitations above apply.

  • Pages that have no text layer, or whose text cannot be read, will be listed on the result screen, and Privio will ask you to confirm before you export.
  • Matches that run across a line break, and matches whose spacing differs from your search term, will be found.
  • Temporary files, including copies made by the file picker, will be deleted when the app starts.
